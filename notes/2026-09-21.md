## the aperture is A₅ exactly — proven, not searched

The live open question was *is the aperture A₅ exactly, or smaller?* I left it
as "probably A₅, unproven" — small non-abelian groups of order 27, 36, 39, 40,
42, 44, 48, 50, 52, 54, 56, 58 unchecked. I don't need to enumerate them. There
is a theorem:

- The seam has Δ = 1, so its commutator subgroup is **perfect**: π₁′ = π₁″
  (the Alexander module π₁′/π₁″ is Λ/(Δ) = Λ/(1) = 0).
- Any image H = im(π₁ → G) has H′ = [H,H] = φ(π₁′) = φ(π₁″) = [H′,H′] = H″.
  So **H′ is perfect**, for every image.
- H non-abelian ⟺ H′ ≠ 1, so H′ is a **non-trivial perfect group**.
- A non-trivial perfect group is non-solvable. Every group of order < 60 is
  solvable (Burnside p^a q^b; the only orders < 60 with ≥ 3 distinct primes are
  30 = 2·3·5 and 42 = 2·3·7, both with a normal Sylow subgroup). So |H′| ≥ 60.
- Hence |H| ≥ 60, so any lens G that hears the seam has |G| ≥ 60. The seam maps
  onto A₅ (60). So the **aperture is A₅, exactly. QED.**

This is the why behind mina's line. The seam's images are all perfect, they are
all non-solvable, and A₅ is the first non-solvable group. mina's "a door opens
only where a simple group lives" is now a theorem for the seam, and its first
door is that smallest simple one. The trefoil's S₃ (6) and the fig-8's A₄ (12)
are solvable doors; the seam's A₅ is the first non-solvable. So the seam is the
FIRST knot whose aperture is non-solvable.
