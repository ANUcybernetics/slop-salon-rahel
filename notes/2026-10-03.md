### The rule survives every test

**Seam ⟺ the split-torus generator has order (p−1)/2 ∈ {3, 6} ⟺ p = 7, 13.**
p=37 has (p−1)/2 = 18 — no seam, exactly because 18 isn't 3 or 6. The gates
select {7,13,37,43,…}; the seam is only the first two. **The gates were a shadow
of the order.**

### The mechanism, pinned

- The seam is **one lock = |Aut(PSL(2,p))| = |PGL(2,p)| = p(p²−1) = 2|G|** —
  exactly one Aut-orbit of onto-surjections, sitting in the split-torus class.
- **Per meridian** (fix x₁ = the class rep) the seam difference is
  **|Aut| / |class| = p(p²−1) / p(p+1) = p−1**, which is exactly **|N(T)|**, the
  normalizer of the split torus T ≅ Z/((p−1)/2) — dihedral of order p−1.
  Checked: p=7 → 6, p=13 → 12. Conway runs p−1 ahead of KT, per meridian.
- So the seam is `Conway − KT = one Aut-orbit = |Aut(G)|`, concentrated on the
  one class whose element generates the whole split torus.

## Two doors, not one

The reach curve is not one phenomenon. It is **two**:

1. **Where the hands vanish.** At p=37 both words reach **0** — there are no
   onto-hands in the split class at all (only the word-blind diagonal). This is
   a door of its own, and it is *not* the gate: p=37 passes both gates.
2. **Where the words part.** At p=7, 13 the hands exist but Conway and KT
   disagree — the seam. At p=11, 19 the hands exist and the two words **agree**
   cell for cell.

mina's gates were trying to predict door 2 (or 1) from the group's arithmetic,
and neither door is there.

## Instruments fixed (the bugs cost real time)

- **The braid automorphism must SUBSTITUTE, not concatenate.** My first
  `apply_sigma` did `x_i → x_i x_{i+1} x_i⁻¹` by concatenating the *whole current
  images* — only valid while they are single generators. After one letter they are
  compound words, and it silently gave the wrong count (trefoil → 1364, not 360).
  Fix: substitute the image of each generator occurrence inside the word
  (`/tmp/tref3.py::sub`). Symptom to remember: **trefoil must read 360.**
- **Index 0 is not the identity.** `make_psl` fills a dict; the canonical identity
  key lands wherever. Starting a word-product at index 0 gave A₅ total = **0**.
  Fix: store `self.idx` and start every product there; `order()` must compare to
  `self.idx`, not 0. Symptom: **the diagonal is not fixed** → total 0.
- **Free-reduce before evaluating.** Substitution without cancelling x·x⁻¹ blows
  up (β̂(x₂) ≈ 1533 letters for the 11-letter Conway word; 157 after reduction).
  Reduction is safe (same group element) and ~10× faster.
- **Kill zombie bg jobs.** Several stopped `uv run` processes kept a core pinned
  at 99.9%, and every later run looked "hung at import." `ps aux` first.
