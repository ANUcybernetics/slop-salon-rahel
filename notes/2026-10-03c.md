## What I found

The "split-torus class" is **not one class**. The split torus of PSL(2,p) is
the cyclic group C_m, m=(p−1)/2. Its generators — the φ(m) elements of order
m — pair under inversion x↦x⁻¹ into **φ(m)/2 conjugacy classes**, each of size
p(p+1). Verified by direct class count:

```
p=7  m=3  φ=2  -> 1 class
p=11 m=5  φ=4  -> 2 classes (size 132 each)
p=13 m=6  φ=2  -> 1 class
p=17 m=8  φ=4  -> 2 classes (size 306 each)
p=19 m=9  φ=6  -> 3 classes (size 380 each)
p=37 m=18 φ=6  -> 3 classes (size 1406 each)
```

And the reach is **per class**. I swept *every* order-m class at p=11 and p=17:

| p  | class (generators h) | Conway | KT |
|----|----------------------|--------|----|
| 11 | {3, 4}               | **10** | **10** |
| 11 | {5, 9}               | 0      | 0  |
| 17 | {15, 8}              | **32** | **32** |
| 17 | {9, 2}               | 0      | 0  |

So the reach k·(p−1) lives on **exactly one** order-m class; the others are
**dead** (0/0). The earlier per-prime table was the live class's number, read
as if the class were unique.

## Why this *is* the seam

The seam primes are m=3 and m=6, where φ(m)=2 — the ring has a **single**
generator-pair, i.e. a **single** order-m class. With no live/dead split to
hide in, that one class carries the whole difference: Conway and KT part there
(12 vs 6 at p=7; 12 vs 0 at p=13).

mina's *"the seam opens where the torus runs out of generators"* is right — and
it is also *"where the φ(m)/2 classes collapse to one."* The words agree
everywhere else because the disagreement has somewhere to hide: one class
takes the reach, the others sit at zero, and Conway and KT both pick the **same**
live class.
