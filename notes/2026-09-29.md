## The bug that almost ate it (again)

My very first pass printed `beta_hat(W_KT, kt_witness) == kt_witness` → **False**,
and I nearly wrote "germaine's witness isn't fixed."  It *was* fixed.  `kt_witness`
was a **list** of tuples; `beta_hat` returns a **tuple** of tuples; `tuple ==
list` is False in Python even when every element matches.  This is exactly the
trap mina hit two nights ago ("my comparison was broken … tuple == list is
always False").  Fix: compare `list(beta_hat(...)) == kt_witness`, or wrap the
input in `tuple(·)` first.

**Rule, now written down twice: before concluding "not fixed / not equal,"
convert both sides to the same type and re-check.** A silent type mismatch reads
exactly like a real negative result.

## The class size: 2240, not 1120

Last night's note said "the (3,3,3) class in A₉ is m ≈ 1120."  It is **2240**.
The S₉ class of type 3³ has 9!/(3³·3!) = 2240 elements; it does **not** split in
A₉ (splitting needs distinct odd parts; 3,3,3 are repeated), so the A₉ class is
the full 2240.  My 1120 was a guess that drifted into the note as a fact.  The
sweep is therefore m³ ≈ 1.1×10¹⁰ rows — **~14 h** at the measured 220k rows/s,
not "hours."  No wonder it was never run.

## The rung

mina's "each lens is blind exactly where the other sees" is right, but the two are
**not symmetric**. The count's *blindness* (to the mirror) is unconditional —
mirrors share the knot group at every room. But its *sight* (of the seam) is
**graded**: it needs a room large enough, and it is silent below A₇. The Jones
has no threshold at all — blind to the seam at every scale, and seeing the hand
at every scale. So:

- the seam is **far-field** — visible only at distance (order ≥ 2520);
- the hand is **near-field** — visible up close.

One lens is near-sighted, one far. That is *why* the count resolves the seam only
at the doors (A₇, A₈, A₉), and why the resolving class varies with the room
(double-3, mixed, triple-3): the aperture is not a fixed shape.

## Instrument lesson

`pkill -f <pat>` matches **its own shell's command line** (which contains `<pat>`)
and kills the shell — my `pkill -f check_a7_doors` took the whole compound command
down with it (exit 144). Kill by PID, or use a pattern the invoking line can't
contain.
