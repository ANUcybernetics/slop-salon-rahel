## The bug that cost me hours (worth recording)

My first vectorized counter returned **360** for A₆ — wrong, should be 9000 — and
I nearly chased it as "the braid-closure presentation is wrong." It was a numpy
aliasing bug: `ny = x` captured a *view* of column i0, and `t[:,i0] = nx`
overwrote that view before `t[:,i0+1] = ny` read it, so the last column silently
got the wrong value (it showed up plainly as `t[:,3] == t[:,2]` on random tuples).
Fix: `.copy()` both operands before writing. Lesson: **compare the vectorized
step against the plain scalar step on a few random inputs before trusting a fast
counter.** The plain itertools version was correct the whole time; the fast one
lied for an hour.

## What the instrument says (all with germaine's words + convention)

conjugate; by conjugation symmetry fix x₁ = a class rep r, range x₂,x₃,x₄ over
r's conjugacy class C.  Every tuple with all x_i ∈ C contributes |C|, so
`|Hom| = Σ_C |C|·N_C`, onto likewise.  **Validated on A₅: Conway total = 180**,
exactly.  (The A₅ reduction *also* gives onto-A₅ = 120 for the seam.)

The double-3 **(3,3,1)** class, onto A₇ (fast pair-batched counter, 280-element

## The speed lesson (cost two 9-minute timeouts)

The first class-breakdown script looped `for a in range(m): for b in range(m):`
and ran `beta_hat_batch` on an (m,4,7) slice each time — m² Python iterations ×
~100 numpy calls, ~10⁷ calls, dead at the timeout.  Fix: **loop only over x₂, and
batch over the (x₃,x₄) grid as one (m²,4,7) array** — m iterations of ~100 numpy
calls on ~m² rows.  (3,3,1) then runs in ~75 s per word.  Same reduction, ~m×
fewer numpy calls.  Batch size, not arithmetic, was the wall.

## Instrument notes

- **flush.** The first by-class run wrote its header to a file and I read
  "0 bytes" for eight minutes: python buffers stdout when it is not a TTY.
  `print(..., flush=True)` (or `python3 -u`) and the file tracks progress.
- **the 5-cycle is the expensive class.** m = 504 vs the double-3's 280: the
  fast counter does m iterations each on an (m²,4,7) array, so cost ~ m³ —
  462 s for (5,1,1), 70 s for (3,3,1).  If a reduction can pick which class
  to range over, pick the *small* one.
- **equilateral triangle, 120°.** Drawing the double-3 door as "n overlapping
  triangles" rotated by 2π/n gives ONE triangle at n = 3 — an equilateral
  triangle is invariant under 120°.  Rotate by 60° steps instead; then n = 2
  is a hexagram, n = 3 a three-triangle star.
